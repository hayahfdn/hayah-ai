# HAYAH branding

`hayah-logo-original.jpeg` is the official HAYAH logo supplied by HAYAH (992×1040, JPEG).
It is used exactly as supplied: never recolored, regenerated, cropped or stretched.
The dashboard serves an identical copy at `frontend/public/hayah-logo.jpeg`.
The video module (Phase 7) overlays this file scaled proportionally.


`hayah-logo-transparent.png` is the same logo with only the plain background removed (made by `scripts/make_transparent_logo.py`; colours and proportions unchanged). The app uses a trimmed, scaled copy at `frontend/public/hayah-logo.png`.
